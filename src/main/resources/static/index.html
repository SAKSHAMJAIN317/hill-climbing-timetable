Hill Climbing Algorithm & Viva Guide

psychology

1. Core Concept of Hill Climbing

What is Hill Climbing?

Hill Climbing is a local search optimization heuristic. It begins with a candidate timetable assignment and iteratively explores neighboring configurations, greedily transitioning to whichever state yields the greatest reduction in penalty violations (steepest descent).

State Space Formulation:

  • State $S$: A complete assignment vector mapping each lecture session to $(Slot_i, Room_i)$.
  • Initial State: Randomly sampled assignment from valid feasible domains.
  • Neighborhood $N(S)$: Timetables reachable by moving one conflicted session to an alternative available room or slot.
calculate

2. Objective Penalty Function

Cost(S) = (HardViolations × 1000.0) + SoftPenalty
Quality Score(%) = 100.0 / (1.0 + 0.005 × Cost(S))

Hard Constraints (×1000 penalty): Zero room clashes, zero faculty double-booking, batch conflict elimination, and lab room type matching.

Soft Constraints (Penalty minimization): Student idle gaps minimization (10 pts), room fatigue prevention (4 pts), and faculty workload balancing.

refresh

3. Overcoming Local Optima (Random Restarts)

The Plateau & Local Optima Problem:

Standard greedy hill climbing can stall when all immediate neighbors have identical or worse penalties (a plateau or ridge with residual clashes).

Multi-Start Random Restarts:

  • Monitors consecutive stagnation steps without penalty improvement.
  • Re-seeds with a fresh candidate schedule while preserving the global best state found so far.
  • Ensures asymptotic completeness and convergence to clash-free global optima.
quiz

4. Viva Q&A Cheat Sheet

Q1: Why Hill Climbing instead of Brute Force?

Brute force has complexity $O(|Domain|^N)$ exceeding $10^{40}$ states. Hill Climbing finds valid solutions in milliseconds via greedy neighborhood traversal.

Q2: How is correctness verified?

An independent ScheduleValidator audits the final timetable. It is stamped VALID only when hard violations are strictly zero.

Q3: How are soft preferences handled?

After reaching zero hard clashes, neighbor evaluation continues to minimize idle gap penalties, consecutive room switches, and instructor daily loads.
